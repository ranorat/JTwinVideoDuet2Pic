# JTwinVideoDuet2Pic

●本ソフトについて  
・１つ又は２つのファイルを左右の描画領域に展開し、フレーム単位(コマ送り・戻し)で調整して  
　立体視用のステレオ画像を静止画として取り出すためだけのツールです。  
・動画ファイルを一つ、又は二つ選択しD&Dして読み込みます。  
・左右の再生・コマ送りや再生時間スライドを使用し、立体視できる位置を探します。  
・左右の描画領域を入れ替える機能があります。  
・左右の一時停止位置(キーマーカー)を５つ保存し、呼び出すことができます。  
・左右同時再生(動作不安定なのでおまけ機能)、左右同時コマ送り機能あり。  
・立体視の位置が確定したら、保存ボタンで左右の画像を保存します。  

●実行方法・環境について  
・Javaソフトであるため、予めJRE（Java実行環境）のインストールをしてください。  
・JavaFXのライブラリが必要になります。容量が大きいのでここにはおいていません。  
　自分でダウンロードし指定場所に配置をお願いします。  
　ダウンロード場所：ttps://gluonhq.com/products/javafx/#downloads  
　　　　　　　　　　該当OS:Windnowsとtype:sdkを選んでください。  
・JTwinVideoDuet2Pic.jarと同じ階層にjavafx-sdkフォルダを作成し  
　その中にSDKの「bin」「legal」「lib」をコピーしてください。  
・JTwinVideoDuet2Pic.jarと同じ階層にある、JTwinVideoDuet2Pic.batを実行して起動します。  

・Windowsにて開発・テストしています。Javaのため実行環境は選びませんが  
　ほかのOSにて動作確認はしていません。  
・コンパイラ：Microsoft OpenJDK version "25.0.4" 2026-07-21 LTS  
・使用ライブラリ：gluon OpenJFX javafx-sdk-26.0.2  
・各OS用のライブラリと実行コマンドをそろえれば恐らく実行できると思います。
